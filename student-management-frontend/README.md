# Student Management System — React Frontend

## Requirements
- Node.js 20 or newer
- Spring Boot backend running at `http://localhost:8080`

## Run
Open a terminal in this folder:
```bash
npm install
npm run dev
```
Open the URL printed by Vite (normally `http://localhost:5173`).

The frontend calls `http://localhost:8080/api/students`. Keep the backend running while using the frontend.

## Features
- List students and search by name, roll number, email, or department
- Create, edit, and delete student records
- Responsive layout for desktop and mobile
- Form validation and API connection error message
